🚌 School Transport Safety Console

A web-based School Transport Safety Console designed to improve the safety, monitoring, and management of school transportation.

The system provides a centralized dashboard for managing school buses, routes, drivers, and student boarding while helping administrators respond quickly to emergencies.

🚀 Features
📍 GPS Tracking
Monitor school transportation using GPS.
Track the current location of buses.
Helps administrators keep an eye on active transportation routes.
🗺️ Route Management
Create and manage school bus routes.
Organize routes for efficient student transportation.
Helps administrators manage transportation schedules and routes effectively.
🎓 Student Boarding Management
Record student boarding information.
Monitor which students have boarded the bus.
Helps improve student accountability and transportation safety.
👨‍✈️ Driver Assignment
Assign drivers to specific buses or routes.
Maintain organized driver-route assignments.
Makes transportation management easier for school administrators.
🚨 Emergency Notifications
Send emergency notifications when an incident occurs.
Provides a quick way to alert relevant users.
Helps improve response time during transportation emergencies.
🛠️ Technologies Used
HTML5 – Structure and layout
CSS3 – Styling and responsive design
JavaScript – Functionality and interactive features
GPS – Bus location tracking

🎯 Project Objective

The main objective of this project is to create a safer and more organized school transportation system.

The console brings important transportation operations into one place, including:

Bus location monitoring
Route management
Student boarding tracking
Driver assignment
Emergency communication

This can help schools improve transportation visibility and respond more efficiently to safety-related situations.

🔐 Safety Focus

Student transportation involves real-time coordination and safety-critical information. This project is designed as a prototype/demo system and should be integrated with proper authentication, secure databases, verified GPS services, and reliable notification infrastructure before being used in a real school environment.
